# Academic Explorer 2.0

Complete Information Retrieval System with:
- TF-IDF, BM25, Boolean Search algorithms
- Inverted Index implementation
- LDA Topic Modeling
- IR Evaluation Metrics (Precision, Recall, MAP, NDCG)
- Citation and Trend Analysis
- Groq AI Integration

## Quick Start
1. cd academic-explorer && npm install && npm run dev
2. cd ../backend && npm install && node server.js
3. Visit http://localhost:5173
